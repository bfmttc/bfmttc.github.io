We optimize motion commands at test time to improve execution, without retraining the behavior foundation model.

Test-Time Command Optimization

TTCO searches for commands that follow the reference more closely. Candidates are evaluated in parallel simulations of the fixed behavior foundation model and robot dynamics.

  1. 1Sample commands
  2. 2Simulate execution
  3. 3Refine the proposal
  4. 4Execute and replan

In simulation, execute a command segment and replan. For policy training, generate command labels offline.

How we allocate compute matters

A fitted cost model selects how many commands to sample, how far to simulate, and when to replan. More compute then produces lower tracking cost.

Compute settings and evaluation+

The plot and both headline values use SONIC fitting motions. Regret measures how far cost exceeds the best measured cost at the same budget. Cost falls by 58.0% as K increases from 256 to 8192.

K = I × N × H / E, where I is search iterations, N is candidates per iteration, H is rollout steps, and E is steps executed before replanning. Applied unchanged to three BFMs on five new motions, the strategy reaches 4.60% mean regret.

The problem

A desired motion is
only the starting point.

A behavior foundation model (BFM) turns motion commands into robot actions. The executed motion can differ from the desired motion, even when the command matches the reference. We call this the command–execution gap.

We introduce Test-Time Command Optimization (TTCO). It searches for commands that produce more accurate execution, using simulations of the fixed BFM and robot dynamics. Additional computation at test time improves tracking without retraining the BFM.

The same method can recover command labels from recorded robot motion. These labels let us train high-level policies and reuse demonstrations with a different BFM.

The method

Search in simulation.
Refine the motion command.

Evaluate the motion a command produces.
Use that result to improve the next proposal.

  1. 01

    Sample commands

    Draw N candidate motion commands from the current proposal.

  2. 02

    Evaluate rollouts

    Run H simulation steps per candidate, starting from the same robot state.

  3. 03

    Update the proposal

    Use candidate costs to refine the search over I iterations.

  4. 04

    Execute and replan

    Execute E steps of the best command in simulation, then repeat from the new state.

↳ Search runs in simulation. Real-robot tracking replays the resulting commands. For policy learning, TTCO generates action labels offline.

02 / Compute allocation

More compute.
A better allocation.

Candidate count, search iterations, rollout horizon, and execution interval compete for the same compute budget. Their allocation affects tracking performance.

We fit a cost model to measured configurations and use it to select a configuration at each budget. On the SONIC fitting motions, the strategy stays close to the best measured configuration across six budgets.

4.02%Mean cost regret
58.0%Measured cost reduction

Regret is the percentage by which cost exceeds the best measured cost at the same budget. The cost reduction is measured as K increases from 256 to 8192.
